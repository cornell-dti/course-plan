# Earth and Climate Sciences (minor)

- Catalog: https://catalog.cornell.edu/programs/earth-atmospheric-sciences-minor/ (2026-2027 edition)
- Data file: `src/data/minors/earth-atmo.ts`
- Checked on 2026-11-13 by `claude-opus-5-5`
- Verdict: **out-of-date**

The required EAS 2250 course and the core list mostly match the catalog. Three things are wrong. The core checker also accepts EAS 3450, which the catalog does not list. The additional-courses requirement asks for one course instead of two. That requirement also never checks the subject, so any non-EAS course at the 3000 level or above satisfies it. The 18-credit minimum is not enforced either.

## Findings

### 1. Additional Courses: 3000 or above (high, count-or-credits)

- **Catalog:** Must select two more EAS courses at the 3000-level or higher.
- **CoursePlan:** perSlotMinCount: [1], so one course fulfils the requirement.
- **Suggested change:** Set perSlotMinCount to [2].

### 2. Additional Courses: 3000 or above (high, course-list)

- **Catalog:** The additional courses must be EAS courses at the 3000-level or higher.
- **CoursePlan:** The checker only tests that catalogNbr does not start with 1 or 2. It never checks the subject, so any course in any department (for example a 3000-level CS or MATH course) is accepted. Courses numbered 0xxx would also pass.
- **Suggested change:** Restrict the checker to EAS courses numbered 3000 or above, e.g. includesWithSingleRequirement('EAS 3**_', 'EAS 4_**', 'EAS 5**_', 'EAS 6_**'), or check course.subject === 'EAS' together with the level.

### 3. Additional Core Courses (high, course-list)

- **Catalog:** The core list is EAS 3050, EAS 3410, EAS 3420, EAS 3090, EAS 3880, EAS 3010, EAS 3030 and EAS 3530. EAS 3450 is not on it.
- **CoursePlan:** The checker also accepts 'EAS 3450', which is cross-listed with EAS 4340. A student could count it as one of the three required core courses.
- **Suggested change:** Remove 'EAS 3450' from the core checker. As an EAS course at the 3000 level or above, it can still count under Additional Courses.

### 4. Minimum credits for minor (medium, count-or-credits)

- **Catalog:** Minimum Credits for Minor: 18. The Engineering rule requires six courses totalling at least 18 credits.
- **CoursePlan:** No requirement checks total credits. EAS 2250 (4 cr) plus three core courses (9 cr) gives 13 credits, so the two additional courses must supply at least 5 credits, and nothing tracks this.
- **Suggested change:** Add a credit-based or self-check requirement for the 18-credit minimum, or state it in a description or checkerWarning.

### 5. Additional Courses: 3000 or above (low, description)

- **Catalog:** The catalog mentions additional core courses and/or EAS 4370 (outside field course) together with an additional 3000-level or higher course. It specifies two courses.
- **CoursePlan:** The description does not give the number of courses and refers to 'undergraduate research courses, and outdoor field courses'.
- **Suggested change:** Update the description to say two EAS courses at the 3000 level or higher, and mention EAS 4370 as the catalog does.

### 6. Additional Core Courses (low, description)

- **Catalog:** The section is titled 'Core Courses': three core courses selected from the list.
- **CoursePlan:** The requirement is named 'Additional Core Courses'. Its source URLs point to the EAS department page under the 'earth-and-atmospheric-sciences-minor' name, not to the catalog's Earth and Climate Sciences minor page.
- **Suggested change:** Rename the requirement to 'Core Courses' and update the source URLs to the current catalog page.
