# Design and Environmental Analysis (minor)

- Catalog: https://catalog.cornell.edu/programs/design-environmental-analysis-minor/ (2026-2027 edition)
- Data file: `src/data/minors/dea.ts`
- Checked on 2026-11-13 by `claude-opus-5-5`
- Verdict: **out-of-date**

The DEA minor file disagrees with the 2026-2027 catalog in its core courses. Slot 1 requires DEA 1050, which the catalog does not list and which was last offered FA23. Slot 2 accepts DEA 1101 and DEA 1200/2200 but rejects the catalog's DEA 1110 (COGST 1111). The DEA 1500 slot does not accept DEA 1501. The file also lacks the required DEA studio course and the 15-credit minimum in DEA courses, and the core description does not match its checker. The upper-level thematic list cannot be checked because the catalog defers the eligible courses to a form.

## Findings

### 1. DEA Core Courses (slot 'DEA 1050') (high, extra-requirement)

- **Catalog:** Core requirements are DEA 1110 or DEA 2200, and DEA 1500. DEA 1050 is not mentioned.
- **CoursePlan:** The first sub-requirement accepts only DEA 1050 (not cross-listed, last offered FA23).
- **Suggested change:** Remove the DEA 1050 slot. If it was meant to stand for the studio requirement, replace it with a separate studio-course requirement.

### 2. DEA Core Courses (slot 'DEA 1110/1200') (high, course-list)

- **Catalog:** DEA 1110 Making a Difference by Design or DEA 2200 Art and Science.
- **CoursePlan:** The checker accepts 'DEA 1101' and 'DEA 1200'. DEA 1200 is cross-listed with DEA 2200, so DEA 2200 is accepted. DEA 1110 (and its cross-listing COGST 1111) is rejected, and DEA 1101 (VISST 1101) is accepted even though the catalog does not list it.
- **Suggested change:** Change the slot to ['DEA 1110', 'DEA 2200'] and drop DEA 1101.

### 3. One DEA studio course (high, missing-requirement)

- **Catalog:** In addition, students must complete one DEA studio course.
- **CoursePlan:** No requirement for a studio course exists.
- **Suggested change:** Add a studio-course requirement with the eligible studio courses, or make it a self-check if the list lives only on the minor form.

### 4. DEA Core Courses (slot 'DEA 1500') (medium, course-list)

- **Catalog:** Requires DEA 1500 Introduction to Environmental Psychology. The Getting Started section names DEA 1501 Introduction to Environmental Psychology - Writing in the Major as the course to complete.
- **CoursePlan:** Only DEA 1500 is accepted (with COGST 1500 and PSYCH 1500). DEA 1501, COGST 1501 and PSYCH 1501 are rejected.
- **Suggested change:** Accept DEA 1501 as an alternative in the DEA 1500 slot.

### 5. Minimum 15 credits in DEA courses (medium, missing-requirement)

- **Catalog:** The minor requires a minimum of 15 credits in DEA courses.
- **CoursePlan:** No credit minimum is encoded. Four core courses plus two thematic courses could total fewer than 15 credits without being flagged.
- **Suggested change:** Add a 15-credit requirement over DEA courses (e.g. 'DEA \*\*\*\*' with fulfilledBy 'credits' and allowCourseDoubleCounting), or a self-check.

### 6. DEA Core Courses description (low, description)

- **Catalog:** DEA 1110 or DEA 2200, and DEA 1500.
- **CoursePlan:** The description reads 'DEA 1101, DEA 1110/DEA 1200, and DEA 1500'. This matches neither the catalog nor the checker, which requires DEA 1050 and accepts DEA 1101 or DEA 1200 in the second slot.
- **Suggested change:** Update the description and slot names to 'DEA 1110 or DEA 2200; DEA 1500 (or DEA 1501)'.

### 7. Eligibility: not a DEA major (low, missing-requirement)

- **Catalog:** To be considered for the Minor in DEA, students must not be a DEA major.
- **CoursePlan:** No exclusion or warning is present.
- **Suggested change:** Mention in a description or checkerWarning that DEA majors are not eligible.

### 8. Upper level DEA thematic courses (low, course-list)

- **Catalog:** The catalog gives no explicit list; it refers to the minor application form.
- **CoursePlan:** The list includes DEA 3600, which is not in the roster data and so can never be added by a student.
- **Suggested change:** Remove DEA 3600, or replace it with its current number if it has been renumbered.
