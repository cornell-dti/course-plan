- Checked on 2026-11-13 by `claude-opus-5-5`
- Verdict: **out-of-date**

The data file for the Applied Economics minor is out of date. The Applied Economics, Various Topics list is missing four catalog courses: AEM 4100, AEM 4110, AEM 4190 and AEM 4880. It also accepts AEM 4515, which the catalog no longer lists. The Economic Theory or Practice requirement accepts ECON 3030 and PUBPOL 2000 for every student, but the catalog limits them to Economics and Public Policy majors. Economics majors need four Various Topics courses, not three. The description also misstates the JCB credit rule. The introductory economics requirement matches.

### 4. Economic Theory or Practice (medium, rule)

- **Suggested change:** Restrict ECON 3030 and PAM 2000/PUBPOL 2000 to the relevant majors, or add a checkerWarning saying they count only for Economics and Public Policy majors respectively. Update the description to match.

- **CoursePlan:** The description says '3 credits must be Johnson College of Business (JCB) courses'.
- **Suggested change:** Change the description to say that 9 credits must be JCB courses and 9 credits must be taken at Cornell.
